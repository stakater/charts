## Note

Scenario 9's ❌ was the test environment, in two steps. First, SeaweedFS ran with S3 auth
disabled, which Velero's object uploads tolerate but Kopia's signed requests don't, so the Kopia
repository couldn't be created (the backup correctly ended PartiallyFailed). Second, kind's
local-path PVs are hostPath volumes, which Velero's file-system backup skips by design. Fixed by
giving SeaweedFS an S3 identity and using an emptyDir volume. Re-run:
[`e2e-kind-2026-09-30-only-9.md`](e2e-kind-2026-09-30-only-9.md): a Kopia file-system backup
Completed, the node-agent counter moved through the chart's PodMonitor, and
OadpNodeAgentUnavailable fired and resolved. 9b passed in every run.
